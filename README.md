Paisa Quest is a personal finance gamified web app that turns budgeting into an interactive adventure. Instead of generic templates, it uses the user's own numbers — salary, savings, and spending choices — to simulate how their money grows over time. Users allocate their income across categories like savings, an emergency fund, investments, and everyday spending, and the app projects the outcomes based on those choices in a playful, "money adventure" format with a pastel visual theme.
